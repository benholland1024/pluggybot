# The serving image's dependencies -- deliberately NOT the project's.
#
# `scripts/serve.py` imports mujoco, numpy, scipy, pillow and websockets and
# nothing else; the rest of pyproject.toml (the demo-video encoder, the
# apriltag GENERATOR) runs at a desk, never on the serving box. Training
# dependencies, when a body needs them (issue #375), stay out of this file.
#
# Versions are the ones in uv.lock, and `tests/test_deploy.py` fails if this
# file drifts from it or if the serve path grows an import that is not here --
# the failure mode otherwise is a green test suite and a container that
# crashes on the server.
# The LLM overseer's client (issue #15). It is imported LAZILY and the
# overseer falls back to the agent's own standing order (`idle` where it has
# left none) when the import or the call fails, so the image would run
# without it -- but a deploy whose mind quietly never answered because a
# package was missing is exactly the silent degradation this file exists to
# prevent, so it is installed.

mujoco==3.10.0
numpy==2.5.1
pillow==12.3.0
